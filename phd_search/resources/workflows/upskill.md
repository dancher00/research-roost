# /upskill — research/training readiness and learning plan

1. Use current opportunity assessments and candidate evidence. Run `./roost gaps` to group recorded gaps across non-vetoed current assessments. PhD, internship and school gaps stay grouped by family; a school's intended learning outcome is not automatically a deficiency for a doctoral application. No assessment coverage means the next task is evaluation, not inventing deficiencies from an empty profile.
2. Distinguish eligibility prerequisites (degree/test/portfolio/access) from research-method gaps, subject/theory gaps, writing/presentation needs and information gaps. A missing source is not evidence of missing skill. Do not advise learning a hard formal prerequisite as if a short course could replace it.
3. Prioritise by actual relevance across target opportunities, upcoming deadlines, transferability and realistic effort. Preserve the supporting opportunity IDs and quotations. If the user selects one posting, focus on its required contribution rather than a generic curriculum.
4. Verify learning resources from primary university/course/project/book documentation and current access/cost. Provide links, prerequisite level, concrete learning objective and a measurable demonstration: a short analysis, annotated bibliography, replication, archival exercise, code artifact, practice study or portfolio component appropriate to the discipline.
5. Propose a feasible schedule with explicitly estimated hours, milestones, feedback and success criteria. Separate a just-in-time application task from a deeper research skill. Do not promise mastery, publication or admission within a fabricated timeframe.
6. Write the substantive plan into the generated report, replacing planning markers. Include a gap/evidence/action/resource/output/date table and a short prioritisation explanation. Completing a course or task becomes a profile fact only when the user confirms what was actually completed.
