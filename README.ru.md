# Research Roost

**Найди следующую исследовательскую возможность — и пойми, почему она тебе подходит.**

От CV и научных интересов к подборке **PhD, исследовательских стажировок, летних и зимних научных школ**, затем — к подготовленной заявке. Для разных научных направлений, с отдельными критериями для каждого типа возможности.

[English](README.md) · MIT · Python 3.11+ · **Альфа 0.2.0a1**

[![Проверки](https://github.com/dancher00/research-roost/actions/workflows/ci.yml/badge.svg)](https://github.com/dancher00/research-roost/actions/workflows/ci.yml)

```text
CV + интересы → профиль исследователя → возможности + первоисточники
             → научное/учебное соответствие + финансирование + допуск
             → документы заявки → проверка → учёт фактической подачи
```

Research Roost работает вместе с AI-агентом, который умеет читать и менять файлы и искать в интернете. Агент исследует и пишет; локальный Python CLI сохраняет доказательства, проверяет материалы и ведёт заявки. Сам CLI модель не вызывает.

## Быстрый запуск

Клонируйте репозиторий и откройте его корневую папку в AI-агенте:

```bash
git clone https://github.com/dancher00/research-roost.git
cd research-roost
./roost init
./roost doctor
```

Нужен Python 3.11+. Основной CLI использует стандартную библиотеку без дополнительных Python-зависимостей и API-ключа модели. Доступ к AI-агенту предоставляет ваша среда. В Windows замените `./roost` на `python -m research_roost`.

Дайте агенту CV или документы о ваших исследованиях и напишите:

> Прочитай AGENTS.md и выполни сценарий setup по моим документам. Собери профиль исследователя с первоисточниками. Уточни недостающие факты и предпочтения; неопределённые темы и страны оставь пустыми. Затем помоги выбрать режим поиска.

Дальше выберите задачу:

| Режим | Пример запроса | Что учитывается |
|---|---|---|
| **PhD** | «Найди PhD по моим научным интересам». | Исследовательский вопрос, методы, руководитель, допуск, финансирование и плата за обучение. |
| **Стажировки** | «Найди исследовательские стажировки на мои даты и уровень обучения». | Проект и ментор, статус студента, продолжительность, оплата и разрешения на работу. |
| **Летние/зимние школы** | «Найди школы, где я освою методы для своего проекта». | Учебная польза, требования, даты сессии, взносы, оплата поездки и жилья. |

Затем дайте ссылку на оригинальное объявление:

> Подготовь мою заявку на эту возможность. Соблюдай реальные требования к документам, обоснуй соответствие моего опыта, отметь неизвестные условия допуска и финансирования и проверь готовые документы.

Обычные фразы работают без slash-команд. Агент использует [AGENTS.md](AGENTS.md), [router](.agents/skills/research-roost/SKILL.md) и [18 сценариев](phd_search/resources/workflows/). Команда `./roost workflow setup` показывает инструкции, но сама профиль не заполняет.

## Чем полезен именно для исследований

- **Соответствие глубже ключевых слов.** Связывает вопросы, методы и подтверждённые работы с проектом, руководителем или учебной целью. Учитывает статьи, книги, программы, данные и художественные работы.
- **Проверяемые первоисточники.** Сохраняет цитаты, даты получения и исходные материалы для оценок. Неизвестное остаётся видимым.
- **Отдельный разбор допуска и финансирования.** Различает плату за обучение, стипендию, взносы, поездку и жильё. У школ отдельно учитываются сроки заявки, финансовой помощи, регистрации и платежа.
- **Заявки с историей.** Помогает написать нужные программе документы, проверить утверждения и файлы, сохранить версии и запись подачи после подтверждения реальной отправки.

Баллы отражают оценку по критериям, а не вероятность поступления. Научное чтение, оценку и написание выполняет агент или человек.

## Попробовать без личных данных

Создайте вымышленный пример и откройте полученный HTML-отчёт:

```bash
python3 tools/demo.py --workspace /tmp/roost-demo --out /tmp/roost-demo.html
```

Путь рабочей папки должен быть новым. Пример содержит синтетические документы, оценку и записи заявки; реальной подачи нет. Также доступны [пример PhD](examples/demo-report.html), [пример стажировки и школы](examples/modes-report.html) и [пояснение](examples/README.md). Скачайте HTML-файлы, чтобы открыть их в браузере.

## Покрытие и личные данные

Встроенный поиск преимущественно ориентирован на Европу и Великобританию. Можно добавлять университетские и стипендиальные источники через HTML, RSS/Atom, JSON или браузерный импорт. Пять встроенных источников стажировок/школ требуют работы агента в браузере. Настраиваемые страны и дисциплины не означают полного мирового покрытия.

Агент может читать доступные GitHub-репозитории, страницы Scholar и публикации своими инструментами. Отдельных коннекторов GitHub/Scholar/ORCID в этой версии нет. Подробнее: [источники](docs/sources.md), [три режима](docs/opportunities.md), [ограничения](docs/limitations.md).

Личный профиль, CV и заявки хранятся в исключённой из Git папке `workspace/`. Личные экспорты и резервные копии сохраняйте вне исходного кода: ignore-правила не удаляют уже закоммиченные файлы. Автоматической отправки писем и заявок нет. Для полного агентского процесса используйте копию репозитория; wheel содержит CLI и тексты сценариев/шаблонов.
